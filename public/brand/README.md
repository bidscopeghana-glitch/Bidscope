# BidScope brand assets

These are the canonical production assets derived from the approved transparent BidScope master logo. The supplied brand-board image is reference material only and is not shipped on the website.

- `logo/bidscope-horizontal.svg`: normal website navigation
- `logo/bidscope-logo-white.svg`: dark green footer and dark surfaces
- `logo/bidscope-mark.svg`: compact product identity
- `logo/bidscope-logo.svg`: full primary lockup with tagline
- `logo/bidscope-monochrome.svg`: one-colour applications
- `icons/`: browser, Apple touch and PWA icons
- `social/bidscope-og.png`: 1200 × 630 social preview
- `templates/`: reusable tender announcement artwork
- `email/signature.html`: safe reusable email signature template

Brand colours are defined once in `app/globals.css`.
